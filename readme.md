Riftbook is a utility for Chromebooks that cannot install the Debian Enviroment inside ChromeOS, either because it does not support it, or for "other" reasons. It uses Termux to install a proot container and displays it on a webpage using Xorg. It's meant to be an install script you just run once, and it works!

<p align="center">
    <img src="Assets/git_banner_4.svg" alt="Riftbook" width="820">
  
Well, if you have the technical know-how on how to install this type of container yourself, go for it! This is meant for the people who either don't have the time or the determination to install this themselves, and just want a ready-to-go preconfigured enviroment

<p align="center">
    <img src="Assets/git_banner_3.svg" alt="Riftbook" width="820">
  
I could just make it a raw install script, but that would intimidate most people, so why not add a visual flare? The installer will auto delete itself once it knows everythings nice & dandy, so whatevers running during the installation process wont hurt your storage much  (your ram might suffer though)
